# vahn-gh.github.io

My personal portfolio, styled as a retro handheld console.

Tabs: PROFILE, WORK, SKILLS, PROJECTS, SCHOOL and TETRIS (playable). Navigate with the on-screen D-pad and A/B buttons or the keyboard (arrows, A/Enter, B/Esc).

Plain static HTML, CSS and JavaScript with no build step and no dependencies.

Deployed on GitHub Pages: https://vahn-gh.github.io/
